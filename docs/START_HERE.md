# Public starter template

This directory is the participant-facing package. It intentionally excludes:

- `AGENTS.md` and `SKILLS.md` with organizer-only future-stage details;
- `solutions/reference/` and `solutions/bad/`;
- `docs/organizer_notes.md`, `docs/calibration_report.md`, private labels, runner logs and flags.

Participants implement `bank_ctf/` until the documented CLI and open checker pass.
